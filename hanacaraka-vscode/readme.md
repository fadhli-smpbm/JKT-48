# Hanacaraka for VS Code

Syntax highlighting, snippets, dan run command buat Bahasa Hanacaraka.

## Fitur

- Syntax highlighting buat `ꦩꦸꦭꦶ`, `ꦫꦩ꧀ꦥꦸꦁ`, `ꦠꦸꦭꦶꦱ꧀`, dll
- Snippet: `prog`, `if`, `while`, `for`, `func`, `proc`, `fib`
- Auto-close `ꦩꦸꦭꦶ` -> `ꦫꦩ꧀ꦥꦸꦁ`
- Font Noto Sans Javanese otomatis

## Cara Pakai

1. Install extension ini
2. Buka file `.pas` atau `.hana`
3. Ketik `prog` + `Tab`
4. `Ctrl + Shift + B` buat jalanin

```pascal
ꦥꦿꦺꦴꦒꦿꦩ꧀ Hello;
ꦩꦸꦭꦶ
  ꦠꦸꦭꦶꦱ꧀(2026);
ꦫꦩ꧀ꦥꦸꦁ.
